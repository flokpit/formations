# Skills

Agent Skills and Claude Code plugins: sources, usage, breed fit, security.

* [Skills Research Summary](summary.md) - Which skill sources are actually used most, which are trustworthy, which skills fit which breed, and what this means for delivering skills to flokpit agents.
* [Community Skill Repositories on GitHub](community-repos.md) - 66 non-Anthropic GitHub repositories that publish Agent Skills or Claude Code plugin marketplaces, sorted by stars, with licence, activity, size, type and notable skills.
* [Skill Marketplaces, Registries and Installers](marketplaces.md) - Where skills and plugins are listed and installed (skills.sh, the official Claude plugin directory, ClawHub, SkillsMP, aitmpl, Tessl, Smithery and others), with the install leaderboards that show which skills are actually used most.
* [Official Skill Sources and the Agent Skills Format](official-sources.md) - The Agent Skills open standard, the SKILL.md format, where Claude Code loads skills from, and every first-party Anthropic repository and plugin marketplace that ships skills.
* [Security of Third-Party Skills](security.md) - Studies and incidents on malicious and vulnerable Agent Skills (ClawHavoc, Snyk ToxicSkills, Unit 42, ESET, academic scans), the attack techniques used, available scanners, and the rules this repository follows when adopting a skill.
* [Skills by Breed](skills-by-breed.md) - Which public skills fit the developer, ui-tester, software-architect, project-manager, reviewer and planner breeds, what each needs inside the agent container, and which do not work headless in a flokpit pod.
